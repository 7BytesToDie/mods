# _Singularity 4.2.0

- New MinEventActionRollEntitySpeed applies a deterministic per-entity multiplier to aggro, aggro-max, and panic speeds. Walk and night speeds can be varied via optional walkMin/walkMax attributes (default 1.0, no change) since walk-cycle animations foot-slide under variation.
- MinEventActionRollEntityScale now multiplies EntityClass.SizeScale instead of replacing it. This composes cleanly with any mod that sets SizeScale, and the action is idempotent, so it can safely fire more than once.
- New SG_FacingConeDegrees property for explosives. When set to a non-zero half-angle, buffs gated on the target's facing direction can suppress themselves when the target is looking away from the blast. Works on both nonlethal and lethal explosives. Example: stun grenades no longer flash a player who was turned away, while still ringing the ears and applying deafness.
- Per-entity rolls for scale, speed, and material variants now use distinct hash salts. An entity's percentile on one axis is no longer correlated with its percentile on another, so a small animal is not also always a slow one or always a particular material variant.
- blocks.xml completely restructured to be load-order agnostic. Each property class (AdvancedSkyManager, ServerPolicies, ScreenEffects, XMLExtensions) is now guarded by its own conditional and populated via prepend, rather than being created inside a single monolithic block. The SingularityConfig block itself is also only appended if it does not already exist. This means other mods can add their own properties to those classes without their patches and Singularity's colliding or overwriting each other, regardless of which loads first.
- blocks.xml documentation rewritten. RollEntityScale's entry now describes the multiplication semantics and idempotency. RollEntitySpeed's entry is new. The Non-Lethal Explosives section gained a Directional Buff Gating subsection with angle guidance and an example, plus a Limitations note explaining that facing gating does not apply to buffs applied outside of an explosion (such as a hitscan weapon adding a buff on hit).
- Material override debug logging is now behind a DEBUG conditional and uses the game's Log.Out rather than Unity's Debug.Log, so no log output appears in Release builds. Parse failures now use Log.Warning instead of Debug.LogWarning.
- Minor code cleanup in EAIRunawayWhenHurtSG: IsEntityBusy simplified to an expression-bodied member, and a string interpolation format specifier fixed.
- Compatibility note: because the roll algorithm gained a salt parameter, existing entities will be assigned new scale, speed, and material variant values on first load. This only affects saves created before 4.2.0 and only matters if you use SG_MaterialColor / SG_MaterialFloat or RollEntityScale on your classes.
